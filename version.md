# Neo Edit Version

## Current Version

0.0.1

## Changelog

### 0.0.1 (2026-04-15)
- Initial release
- Tabbed text editor with Monaco Editor
- Syntax highlighting for 50+ languages
- Light, Dark, Tokyo Night, and Mariana themes
- Word wrap settings (70, 75, 80, custom)
- Find & replace
- Settings panel (font size, theme, word wrap)
- Markdown editing: live preview, outline, formatting shortcuts, tables, export
- Open / save / save as / close tab / close all
- Session recovery for unsaved files
- Window position save/restore
- .docx and .doc file support (read & write)
- Native macOS print support
- Paste with formatting (Cmd+Shift+V)
- Quit application (Cmd+Q)
